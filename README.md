# screen-kit

Product demo videos as code, made and checked by coding agents.

A script lists the steps: what the cursor, trackpad, finger or keyboard does, and what the
narrator says in each language. screen-kit records the steps once in a real browser, then
renders the video from a timeline: a wallpaper stage, a browser or device frame, a camera that
zooms and pans, a crisp cursor with click ripples, gesture and keystroke overlays, captions and
voice. Every render checks itself against the script, so an agent can fix and re-render without
anyone watching, and a human only approves.

Status: design. Read [docs/SPEC.md](docs/SPEC.md); the research behind it is in
[docs/research](docs/research).
